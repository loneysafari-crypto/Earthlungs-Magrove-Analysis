How to Use the Kisutu I, II & III Mangrove Monitoring System

Follow these simple steps to explore mangrove cover, canopy health, burn severity, and restoration priority across the Kisutu 1, 2 and 3 area using Google Earth Engine.

Step 1: Select Your Date Range

In the "Run Custom Analysis" panel, set a Start and End date. For a single snapshot (NDVI, EVI, mangrove coverage), both dates define one composite window. For a change analysis, Start is treated as the "before" date and End as the "after" date.

Step 2: Select an Analysis Type

Choose what you want to map from the dropdown:
• NDVI (single period) or NDVI change (Start vs End)
• EVI – canopy density (single period)
• Burn severity class (Start = pre-fire, End = post-fire)
• Mangrove coverage (single period)
• Mangrove change (Start vs End) — loss / stable / gain
• Mangrove restoration priority (Start = baseline, End = current)
All layers are built from Sentinel-2 (2016 – present) surface reflectance imagery.

Step 3: Run the Analysis

Click "Run Analysis" and wait while the system processes the satellite data — the button is replaced with a "Running analysis, please wait…" indicator until the result is ready.

Step 5: View the Results

The new layer appears on the map with its legend (bottom-right). Where an analysis produces a summary chart — mangrove coverage, mangrove change, burn severity, or restoration priority — that chart also opens in its own panel (top-right, above the legend), and can be dismissed with its "Close chart" button. Use Earth Engine's built-in Layers control (top-right) to toggle any layer on or off.

Tips for Best Results

  • Use Google Chrome or Microsoft Edge for the best performance.
  • Processing time depends on your date range and analysis type — wider windows and multi-year trends take longer than a single-season snapshot.
  • For change analyses, pick a Start and End date that bracket the event or period you want to study (e.g. before and after a known fire, or a baseline year vs. today).
  • Compare multiple date-range runs to observe how mangrove cover and restoration needs change over time across Kisutu I, II and III.
  • Make sure you have a stable internet connection, since each run queries Earth Engine in real time.
