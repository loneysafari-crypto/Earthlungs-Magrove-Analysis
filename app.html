How to Use the System

Follow these simple steps to explore mangrove cover, canopy health, burn severity, and restoration priority across the Tanzania Sites area using Google Earth Engine.

Step 1: Set the Date Range

In the "Tanzania Sites Analysis" panel, set the Start date and End date (YYYY-MM-DD).
This defines the period for which the satellite data will be processed.

Step 2: Choose a Layer

Select the analysis layer from the dropdown menu. The available layers include:
• NDVI – vegetation health
• EVI – canopy density
• NBR – burn severity
• MNDWI – water and land separation
• Mangrove coverage
• Mangrove change
• Restoration priority
All layers are built from Sentinel-2 imagery.

Step 3: Set Cloud Cover (Optional)

Use the slider to set the maximum cloud cover percentage. Lower values give clearer results, while higher values include more data.

Step 4: Select the Area to Display

Choose the area you want to analyze. You can select "ALL AREAS" or a specific region from the dropdown.

Step 5: Update the Map

Click the "Update map" button. The system will process the data and display the selected layer on the map with its legend and, where available, a summary chart.

Tips for Best Results

  • Use Google Chrome or Microsoft Edge for the best performance.
  • Processing time depends on your date range and analysis type — wider windows and multi-year trends take longer than a single-season snapshot.
  • For change analyses, pick a Start and End date that bracket the event or period you want to study (e.g. before and after a known fire, or a baseline year vs. today).
  • Compare multiple date-range runs to observe how mangrove cover and restoration needs change over time across Tanzania Sites.
  • Make sure you have a stable internet connection, since each run queries Earth Engine in real time.
